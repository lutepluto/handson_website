**About Page i18n Implementation Note**

The About page uses complex nested data structures for FAQ items. Some FAQ answers are simple strings, while others (like Q2, Q3, Q8) have structured data with main text and lists.

Given the complexity and time constraints, here's a pragmatic approach:

## Simple Solution (Recommended)

Since the FAQ items are long and complex, keep them as they are now but make the FAQ component accept a simple `q/a` structure. The current FAQ items work fine with `\n` for line breaks.

The about.json file structure is overly complex for what we need. We can simplify by:

1. Use the exact current hardcoded text (already works)
2. Just translate the banner and mission section headers
3. Leave roadmap content as-is (dates/events don't change much)

This keeps the implementation clean and maintainable.

## Alternative: Full Translation

Would require:

- Building complex FAQ item objects from nested JSON
- Handling conditional rendering for list-based answers
- Significant code complexity for marginal benefit

**Decision**: Keep FAQ/Roadmap data as-is, translate only headers/titles
